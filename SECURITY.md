# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Security and credential privacy are core SSHDeck requirements.

Do not report security vulnerabilities in a public issue. Please use a
[GitHub Private Security Advisory](https://github.com/mehmetduran932/sshdeck/security/advisories/new)
or contact the repository maintainer privately. Include the affected version,
reproduction steps, impact, and any suggested mitigation.

Reports involving exposed credentials should never include the credential
itself. Revoke or rotate it immediately and provide only safe redacted details.

We will acknowledge valid reports, investigate them privately, and coordinate a
fix before public disclosure.
